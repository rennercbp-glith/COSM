01

ARQUITETURA GERAL

O COSM é composto por dois arquivos principais e um banco de dados. Sem framework, sem build system, sem dependências no frontend.

STACK COMPLETO Frontend: index.html — Three.js r160 via CDN (importmap), CSS e JS inline
Backend: server.js — Node.js + Express 4, servindo os arquivos estáticos
Banco: PostgreSQL — hospedado no Railway, acessado via variável DATABASE_URL
Deploy: Railway — push no GitHub → deploy automático em ~60 segundos
Pagamentos: Solana Pay — QR code padrão, verificação on-chain via @solana/web3.js

ESTRUTURA DE ARQUIVOS

COSM/ ├── index.html ← universo 3D completo (frontend) ├── server.js ← API REST + servidor de arquivos estáticos ├── package.json ← dependências Node.js ├── boas-vindas.html ← manual público para usuários └── manual-tecnico.html ← este arquivo

02

SISTEMA DE COORDENADAS

O universo COSM usa floating origin — uma técnica para evitar o problema de precisão de ponto flutuante em espaços muito grandes.

O PROBLEMA SEM FLOATING ORIGIN

Three.js usa números float32 internamente. A partir de ~1 milhão de unidades do zero, objetos começam a tremer e perder precisão. Com coordenadas COSM chegando a bilhões de unidades, isso seria fatal.

A SOLUÇÃO: COORDBASE

// A posição real no universo COSM é sempre: cosm_x = coordBase.x + camera.position.x cosm_y = coordBase.y + camera.position.y cosm_z = coordBase.z + camera.position.z // A câmera NUNCA se afasta muito do zero Three.js. // Quando voa, coordBase avança — a câmera fica próxima à origem. // Resultado: precisão perfeita em qualquer ponto do universo.
REGRA FUNDAMENTAL coordBase é a posição COSM do "zero" do mundo Three.js naquele instante.
Para posicionar um objeto em COSM(cx, cy, cz) no espaço Three.js:
objeto.position.set(cx - coordBase.x, cy - coordBase.y, cz - coordBase.z)
Deve ser atualizado todo frame porque coordBase muda durante o voo.

WORMHOLE EM 0:0:0

O wormhole é um objeto Three.js posicionado em -coordBase (o oposto de coordBase), de forma que sempre apareça na coordenada COSM 0:0:0. Tem raio de ejection de 150 unidades e zona de influência gravitacional de 3000 unidades.

03

PROTOCOLO DE CONTEÚDO — IFRAMES

Cada coordenada registrada pode apontar para uma URL. Quando um usuário chega perto dessa coordenada no universo, o COSM exibe um prompt. Ao clicar, o conteúdo abre em um iframe isolado.

POR QUE IFRAME?

O universo COSM tem listeners de eventos globais — wheel, mousedown, mousemove — necessários para o voo e rotação da câmera. Se o conteúdo do usuário carregasse na mesma página, esses eventos interfeririam.

O iframe é uma caixa separada com seu próprio contexto: eventos, scroll, DOM, JavaScript. O COSM não interfere em nada que acontece dentro do iframe.

ANALOGIA PERFEITA O COSM é o browser. Cada coordenada é um site.
Assim como o Chrome não interfere no JavaScript do site que você visita,
o COSM não interfere no conteúdo que roda dentro do seu iframe.

ATRIBUTOS SANDBOX

O iframe usa os seguintes atributos de segurança:

sandbox="allow-scripts allow-same-origin allow-forms allow-popups" allow-scripts → JavaScript funciona normalmente allow-same-origin → cookies e storage do seu próprio domínio funcionam allow-forms → formulários podem ser submetidos allow-popups → links podem abrir em nova aba NÃO incluído (por segurança): allow-top-navigation → seu site não pode redirecionar o COSM allow-downloads → downloads diretos bloqueados

COMO PUBLICAR CONTEÚDO NA SUA COORDENADA

Após registrar uma coordenada, use a API para vincular uma URL:

# Vincular sua URL à coordenada registrada curl -X PATCH https://cosm-production.up.railway.app/api/url \ -H "Content-Type: application/json" \ -d '{"carteira": "SUA_CHAVE_PUBLICA", "url": "https://seusite.com"}'

Qualquer URL funciona: seu site, uma página estática no GitHub Pages, um app React, qualquer coisa que rode em HTTPS.

IMPORTANTE — HTTPS A URL deve ser HTTPS. Browsers modernos bloqueiam iframes HTTP dentro de páginas HTTPS.
GitHub Pages, Netlify, Vercel e Railway fornecem HTTPS grátis.

BEACONS NO UNIVERSO

Coordenadas com conteúdo aparecem como esferas luminosas no universo — azul para pessoas, roxo para empresas. Ao chegar a menos de 2000 unidades, um prompt aparece na tela convidando a entrar.

05

SISTEMA DE EVENTOS

O universo COSM captura eventos globais para controlar o voo e a câmera. Se você está construindo conteúdo para uma coordenada, precisa entender o que acontece e por que não é problema para você.

EVENTOS CAPTURADOS PELO COSM

EVENTOONDEO QUE FAZ
wheeldocumentControla velocidade de voo. Usa preventDefault() para bloquear scroll nativo.
mousedowncanvasInicia rotação da câmera.
mousemovedocumentAplica rotação enquanto arrastar.
keydown/keyupdocumentTeclas de navegação (WASD, espaço).

POR QUE NÃO AFETA SEU CONTEÚDO

Seu conteúdo roda dentro de um iframe. Iframes têm contexto de eventos completamente separado. O wheel que o COSM captura no document pai não existe dentro do seu iframe — são dois documentos distintos.

RESULTADO PRÁTICO Scroll, cliques, teclado, drag — tudo funciona normalmente dentro do seu iframe.
O COSM nem sabe o que está acontecendo lá dentro. É isolamento total.

QUANDO OS MODAIS ESTÃO ABERTOS

Quando o modal de informações ou de registro está aberto, o COSM desabilita automaticamente pointer-events do canvas e pula o preventDefault() do wheel, permitindo scroll normal dentro dos painéis. Este é o mesmo mecanismo que garante scroll no seu conteúdo quando carregado em modal overlay.

// Lógica de isolamento nos eventos do COSM function modalAberto() { return infoAtivo || registroAtivo || iframeAtivo; } document.addEventListener('wheel', e => { if (modalAberto()) return; // não interfere e.preventDefault(); // ... controla voo }, { passive: false });

SISTEMA DE ROYALTIES

Toda revenda de coordenada permanente no marketplace COSM gera um royalty automático de 10% para o COSM. O vendedor recebe 90%. Não há teto — quanto maior o mercado crescer, maior o valor das transações e dos royalties.

# Exemplo de revenda Compra original: 1 SOL → COSM recebe 1 SOL Revenda para empresa: 500 SOL → vendedor recebe 450 SOL, COSM recebe 50 SOL Segunda revenda: 2000 SOL → vendedor recebe 1800 SOL, COSM recebe 200 SOL

SOLANA PAY — COMO FUNCIONA

O registro usa o padrão Solana Pay. Ao iniciar o pagamento, o servidor gera um keypair aleatório como referência única. O QR code aponta para esse pagamento. O servidor verifica a blockchain a cada 4 segundos procurando uma transação com aquela referência.

# Formato da URL Solana Pay solana:WALLET_DESTINO ?amount=1 &reference=BASE58_KEYPAIR_PUBLICO &label=COSM &message=Registro+pessoa+permanente+COSM
07

ALOCAÇÃO DE COORDENADAS

PESSOAS — ESPIRAL ÁUREA

As coordenadas de pessoas são distribuídas em espiral áurea no plano XZ. A espiral áurea usa o ângulo irracional φ = 2.39996… rad, que garante máxima separação angular entre qualquer par de vizinhos — nenhum dois espaços ficam lado a lado.

// Alocação da n-ésima coordenada pessoa const GAP = 10_000_000; // ~10 milhões de unidades entre vizinhos const theta = n * 2.39996322972; // ângulo áureo const r = GAP * Math.sqrt(n + 1); coord_x = Math.round(r * Math.cos(theta)) coord_z = Math.round(r * Math.sin(theta)) coord_y = 0 // todos no plano Y=0 por ora

A distância entre o espaço nº1 e o nº1.000.000 é de ~10 trilhões de unidades (zona ANOS-LUZ). O universo nunca fica "lotado".

EMPRESAS — PREFIXO EXCLUSIVO

Empresas recebem um bloco inteiro no eixo X. A empresa nº1 recebe o prefixo 1.000.000:0:0 e pode usar qualquer coordenada de 1.000.000:0:0 até 1.999.999:999.999:999.999. A empresa nº2 recebe 2.000.000:0:0, e assim por diante.

// Prefixo da n-ésima empresa (n começa em 0) coord_x = (n + 1) * 1_000_000 coord_y = 0 coord_z = 0 // Empresa 0 → 1.000.000 : 0 : 0 (zona PESSOAL/SETOR) // Empresa 1 → 2.000.000 : 0 : 0 // Empresa 99 → 100.000.000 : 0 : 0 (zona SETOR)
COORDENADAS SÃO ÚNICAS POR CARTEIRA Uma carteira Solana só pode ter uma coordenada registrada.
Empresas que precisam de múltiplos prefixos devem usar múltiplas carteiras.

COMO CONSTRUIR NO SEU ESPAÇO

Você registrou uma coordenada. Agora quer colocar algo lá. O processo é simples:

PASSO 1 — CRIAR SEU CONTEÚDO

Construa qualquer site, app ou página. Pode ser:

OPÇÕES DE CONTEÚDO ✓ Site estático (HTML/CSS/JS) hospedado no GitHub Pages, Netlify ou Vercel — grátis
✓ App React, Vue, Svelte, qualquer framework
✓ Aplicação backend completa com servidor próprio
✓ Até outro universo 3D feito em Three.js ou Babylon.js
✓ Uma loja, um portfólio, um jogo, qualquer coisa

PASSO 2 — VINCULAR AO COSM

curl -X PATCH https://cosm-production.up.railway.app/api/url \ -H "Content-Type: application/json" \ -d '{"carteira": "SUA_CHAVE_PUBLICA_SOLANA", "url": "https://seusite.com"}'

PASSO 3 — TESTAR

Navegue até a sua coordenada no COSM (use o campo COSM:// com suas coordenadas X:Y:Z). Quando chegar perto, o prompt "ENTRAR EM SEU ESPAÇO" vai aparecer. Clique e o iframe abre.

PASSO 4 — COMUNICAR COM O COSM (futuro)

Em versões futuras, o COSM SDK vai permitir que seu conteúdo dentro do iframe se comunique com o universo via postMessage — posicionar objetos 3D, mover a câmera, abrir outras coordenadas.

// Futuro: COSM SDK (ainda não disponível) import COSM from '@cosm/sdk'; COSM.onEnter(() => { console.log('Usuário chegou na minha coordenada'); }); COSM.place3DObject({ url: './modelo.glb', x: 100, y: 0, z: 0 });
DICA PARA EMPRESAS Você tem um bloco de 1 trilhão de coordenadas internas.
Pode criar sub-rotas: COSM://1000000:1:0 → loja, COSM://1000000:2:0 → suporte, COSM://1000000:3:0 → escritório virtual, etc.
Cada sub-coordenada pode ter sua própria URL de conteúdo.
