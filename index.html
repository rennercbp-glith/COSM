03 — PARA DESENVOLVEDORES

A coordenada é
sua barra de endereço.

Quem registra uma coordenada tem controle absoluto sobre ela — câmera, navegação, física, renderização. Tudo pode ser sobrescrito. É como se você digitasse uma URL e chegasse num universo 3D que você mesmo criou.

// Hook de loop — roda a cada frame quando o usuário está na sua coordenada window._cosmLoop = (dt) => { meuObjeto.rotation.y += dt * 0.5 meuObjeto.position.y = Math.sin(Date.now() / 600) * 20 } // Controle de câmera — desativa navegação padrão do COSM window._cosmControls = false camera.position.set(0, 80, 200) camera.lookAt(0, 0, 0)

_cosmLoop(dt) — função chamada todo frame enquanto o visitante estiver na sua área.
_cosmControls = false — assume controle total da câmera (mouse/teclado do COSM são desativados).
Ambos são removidos automaticamente ao sair da coordenada.

04 — API REFERENCE

REST. Sem SDK.
Sem chave na beta.

POST /api/registrar
Registra coordenada → { coord_x, coord_y, coord_z }
body: { carteira, tipo, plano, nome }
PATCH /api/url3d
Define objeto 3D (.glb / .gltf público)
body: { carteira, url }
PATCH /api/url
Define conteúdo web da coordenada
body: { carteira, url } — qualquer HTTPS
GET /api/coordenadas
Lista coordenadas com objetos 3D ativos
→ [ { coord_x, coord_y, coord_z, url_3d, nome } ]
GET /api/minha-coord/:x/:y/:z
Verifica existência e dono → { existe: bool }

TIPOS DE CONTEÚDO
TIPO 01 — PÁGINA WEB
Qualquer URL HTTPS renderizada em tela cheia
Portfólio, loja (Shopify, WooCommerce), app React/Vue/Svelte hospedado no Vercel ou Netlify, dashboard interno, Notion público, Google Sites, vídeo embed, mapa interativo. Funciona via iframe com sandbox — seus eventos de scroll, clique e teclado funcionam normalmente dentro do espaço.

TIPO 02 — OBJETO 3D NATIVO (.glb / .gltf)
Modelo 3D solto no universo — sem moldura, sem bordas
O arquivo é carregado diretamente na cena Three.js do COSM. O objeto flutua no espaço como se fosse parte do universo — igual o wormhole existe no centro. Animações do arquivo tocam automaticamente. Exporte do Blender, Unity, Unreal, Spline ou qualquer ferramenta que gere .glb.
url_3d: "https://meucdn.com/cidade.glb"  ·  escala, posição e rotação configuráveis
TIPO 03 — CÓDIGO AO VIVO (EM BREVE)
Escreva Three.js diretamente — o objeto aparece no universo
Um editor de código dentro do COSM. Você escreve, dá enter, o objeto aparece na sua coordenada em tempo real. Sem hospedar arquivo. Sem deploy. O código roda na engine do COSM com acesso a THREE, geometrias, materiais, luzes, física e animações procedurais.
const geo = new THREE.TorusKnotGeometry(100, 30)
const mat = new THREE.MeshStandardMaterial({ color: 0xff6600 })
return new THREE.Mesh(geo, mat)  →  aparece no espaço
