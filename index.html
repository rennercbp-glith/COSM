TIPOS DE CONTEÚDO
TIPO 01 — PÁGINA WEB
Qualquer URL HTTPS renderizada em tela cheia
Portfólio, loja (Shopify, WooCommerce), app React/Vue/Svelte hospedado no Vercel ou Netlify, dashboard interno, Notion público, Google Sites, vídeo embed, mapa interativo. Funciona via iframe com sandbox — seus eventos de scroll, clique e teclado funcionam normalmente dentro do espaço.
url_conteudo: "https://meusite.vercel.app"
TIPO 02 — OBJETO 3D NATIVO (.glb / .gltf)
Modelo 3D solto no universo — sem moldura, sem bordas
O arquivo é carregado diretamente na cena Three.js do COSM. O objeto flutua no espaço como se fosse parte do universo — igual o wormhole existe no centro. Animações do arquivo tocam automaticamente. Exporte do Blender, Unity, Unreal, Spline ou qualquer ferramenta que gere .glb.
url_3d: "https://meucdn.com/cidade.glb"  ·  escala, posição e rotação configuráveis
TIPO 03 — CÓDIGO AO VIVO (EM BREVE)
Escreva Three.js diretamente — o objeto aparece no universo
Um editor de código dentro do COSM. Você escreve, dá enter, o objeto aparece na sua coordenada em tempo real. Sem hospedar arquivo. Sem deploy. O código roda na engine do COSM com acesso a THREE, geometrias, materiais, luzes, física e animações procedurais.
const geo = new THREE.TorusKnotGeometry(100, 30)
const mat = new THREE.MeshStandardMaterial({ color: 0xff6600 })
return new THREE.Mesh(geo, mat)  →  aparece no espaço
