TIPO 1 — PÁGINA WEB (url_conteudo):
  Qualquer URL HTTPS → abre em iframe full-screen na coordenada.
  Sandbox: allow-scripts allow-same-origin allow-forms allow-popups.
  Tela com moldura (barra do COSM no topo).
  Scroll e eventos funcionam normalmente dentro do iframe.

TIPO 2 — OBJETO 3D NATIVO (url_3d):
  Arquivo .glb/.gltf → carregado via GLTFLoader direto na cena Three.js.
  SEM moldura. SEM iframe. O objeto FAZ PARTE do universo.
  Animações tocam automaticamente via AnimationMixer.
  Posição atualizada todo frame via floating origin (coordBase).
  Escala padrão: 500 unidades.
  Usuário hospeda o .glb em qualquer CDN com CORS aberto.

TIPO 3 — CÓDIGO AO VIVO (em desenvolvimento):
  Editor de código dentro do universo.
  Usuário escreve Three.js → objeto aparece no espaço instantaneamente.
  Sem hospedar arquivo. Sem deploy. Roda na engine do COSM.
  Retorna THREE.Object3D → adicionado à cena na posição atual.

  BUGS CONHECIDOS E COMO EVITAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. let/const antes de loop(): TODA variável usada dentro do loop() —
   ou em funções chamadas pelo loop() (ex: processarGamepad) — deve ser
   declarada ANTES da linha loop() ser CHAMADA (linha ~1631).
   let/const têm Temporal Dead Zone: acessar antes da declaração =
   ReferenceError silencioso → tela preta, loop travado, nada funciona.
   Variáveis com function declaration (hoisted) são seguras, mas as que
   elas referenciam com let/const não são.
   BUG JÁ ACONTECEU: gamepadAtivo declarado em linha 2048, loop() em 1631.
   Fix: mover para junto das outras vars de navegação (linha ~1317).

2. Scroll bloqueado: o wheel handler global tem
   if (modalAberto()) return; ANTES do preventDefault.
   Se remover isso, scroll dos modais para de funcionar.

3. Canvas bloqueando cliques: bloquearCanvas(true) ao abrir qualquer
   modal ou iframe. bloquearCanvas(false) só quando TUDO estiver fechado.
   modalAberto() verifica: modal-info, modal-reg, modal-teste,
   modal-inserir E modal-controles. Atualizar sempre que adicionar modal.

4. Funções no onclick HTML: toda função chamada por onclick deve estar
   em window.funcao = function(){}. Funções dentro de type="module"

ESCALA DO HUD — formatCoord + zonaAtual
  4 zonas: LOCAL (<1k) → PESSOAL (1k–1M) → SETOR (1M–1G) → ANOS-LUZ (>1G)

  function formatCoord(v) {
    const s = v < 0 ? '-' : '';
    const a = Math.abs(v);
    if (a >= 1e9) return s + (a/1e9).toFixed(2) + 'A'; // Anos-luz
    if (a >= 1e6) return s + (a/1e6).toFixed(2) + 'S'; // Setor
    if (a >= 1e3) return s + (a/1e3).toFixed(1) + 'k'; // Pessoal
    return s + Math.round(a) + 'm';                      // Local
  }

  function zonaAtual(c) {
    const m = Math.max(Math.abs(c.x), Math.abs(c.y), Math.abs(c.z));
    if (m >= 1e9) return { label:'ANOS-LUZ', cor:'rgba(180,140,255,0.7)' };
    if (m >= 1e6) return { label:'SETOR',    cor:'rgba(100,200,255,0.7)' };
    if (m >= 1e3) return { label:'PESSOAL',  cor:'rgba(100,255,180,0.7)' };
    return             { label:'LOCAL',     cor:'rgba(255,255,255,0.4)' };
  }

ALOCAÇÃO DE COORDENADAS — server.js
  Pessoas: Esfera de Fibonacci → distribui em X, Y, Z (não espiral 2D)
  Empresas: Eixo X exclusivo (bloco de 1M por empresa)
  GAP = 1.000.000 → espaço enorme, coordenadas embaralhadas (intencional)
  O embaralhamento vem da fórmula Fibonacci, não de aleatoriedade.

  const GAP = 1_000_000;

  function alocarCoordenada(totalPessoas) {
    const i     = totalPessoas;
    const phi   = Math.acos(1 - 2 * (i + 0.5) / 10000);
    const theta = i * 2.39996322972; // ângulo áureo em radianos
    const r     = GAP * Math.sqrt(i + 1);
    return {
      x: Math.round(r * Math.sin(phi) * Math.cos(theta)),
      y: Math.round(r * Math.cos(phi)),
      z: Math.round(r * Math.sin(phi) * Math.sin(theta))
    };
  }

  function alocarCoordenadaEmpresa(n) {
    return { x: (n + 1) * 1_000_000, y: 0, z: 0 };
  }
