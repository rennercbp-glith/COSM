Um sistema de armazenamento digital eterno baseado em
coordenadas espaciais 3D num universo virtual fixo e infinito.

Em vez de endereços aleatórios (como 0x4f3a... do Bitcoin),
cada arquivo tem um endereço visual e memorável:
  COSM://2800:120:-1600

O universo é fixo — as coordenadas nunca mudam.
O espaço é infinito — os endereços nunca acabam.
O arquivo é eterno — distribuído em nós pelo mundo.

Diferencial principal:
  → A pessoa NAVEGA até o arquivo no espaço 3D
  → Funciona com óculos VR (Meta Quest, Apple Vision Pro)
  → Mais intuitivo que qualquer blockchain existente
  → Sem nome, sem CPF, sem banco — só chave criptográfica

O universo é UM SÓ para todos os usuários do mundo.

Um usuário no Brasil e um no Japão navegam no MESMO espaço.
Se o brasileiro registrou um arquivo em 500:80:0, o japonês
pode navegar até lá e VER o objeto flutuando.

VISIBILIDADE vs ACESSO — são coisas diferentes:
  OBJETO VISÍVEL → qualquer um vê o cubo/arquivo flutuando
  CONTEÚDO BLOQUEADO → só abre com a chave privada do dono

  É igual ao Bitcoin:
  Qualquer um vê que existe uma carteira em 0x4f3a... com 5 BTC.
  Mas ninguém move sem a chave privada.

CONCEITO CENTRAL:
  Cada usuário entra no universo em um ponto DIFERENTE a cada vez,
  a não ser que faça login com seu token (chave criptográfica).
  O IP é usado como semente matemática para gerar uma coordenada
  única em escala de anos-luz — garantindo que usuários nunca
  fiquem próximos por acidente e o espaço nunca fique "poluído".

COMO FUNCIONA O IP → COORDENADA:
  IPv4 tem 4 números: ex. 187.45.12.200
  → Usar os 4 octetos como semente de um gerador de coordenadas
  → Cada octeto gera uma dimensão em escala de anos-luz
  → Resultado: A 187.045:45.012:12.200  (escala galáctica única)
  → IPs diferentes = regiões do universo imensamente distantes
  → O espaço de cada pessoa é grande o suficiente para nunca
    colidir com o do vizinho

PROBLEMA: IPs podem se repetir (DHCP, VPN, IPs compartilhados)
SOLUÇÃO: IP + seed aleatório gerado na primeira visita (salvo em
  IndexedDB). Mesmo IP mas seed diferente = coordenada diferente.
  A seed é o que realmente ancora o usuário no espaço anonimamente.

USUÁRIO SEM LOGIN (anônimo):
  → Na primeira visita: IP + seed aleatório → coordenada temporária
  → Seed salva localmente (IndexedDB) → mesma posição ao voltar
  → Se limpar o browser: seed some, nova posição gerada
  → Nunca tem nome, email ou identificação

USUÁRIO COM LOGIN (token / chave criptográfica):
  → Gera par de chaves: pública + privada (no dispositivo)
  → Chave pública → hash → coordenada PERMANENTE no universo
  → Mesma chave = mesma posição em qualquer device, sempre
  → Chave privada nunca sai do dispositivo — é a identidade

ESTRUTURA DE ESCALAS POR TIPO DE ESPAÇO:
  Anos-luz (A)  → espaço do USUÁRIO/SESSÃO
                   cada pessoa em uma região galáctica única
                   ex: A 187.0:45.0:12.2

  Setor (S)     → espaço de EMPRESAS / organizações
                   regiões registradas e nomeadas
                   ex: S 500.0:0.0:0.0 (Nike Store)

  Km (k)        → espaço PESSOAL dentro da região do usuário
                   onde ficam os arquivos, pastas, portais
                   ex: 500:80:0 k (dentro do meu espaço)

SISTEMA DE VISIBILIDADE (privacidade granular):
  Dentro do espaço pessoal (km), o dono controla o que aparece:

  VISÍVEL    → objeto flutua no espaço, qualquer visitante vê
  INVISÍVEL  → objeto existe mas não aparece para ninguém
  COMPARTILHADO → dono envia a coordenada exata para alguém

  EXEMPLO REAL:
    Meu amigo me envia: A 187.0:45.0:12.2
    → Digito no COSM://, voo até lá (anos-luz de distância)
    → Chego perto o suficiente → entro na escala km

IDEIA FORTE — Sistema de prefixo por escala de distância:
  Em vez de exibir números brutos (ex: 1500000:200000:0),
  o painel comprime automaticamente conforme a distância:

  Coordenada bruta       → Exibição no painel
  0 a 999                → 500:80:0 m       (zona do arquivo)
  1.000 a 999.999        → 1.5:0.08:0 k     (navegação local)
  1.000.000 a 999.999.999→ 1.5:0.08:0 S     (entre setores)
  acima de 1.000.000.000 → 1.5:0.08:0 A     (escala galáctica)

  Prefixos sugeridos:
    m = metros       (escala do arquivo, operação)
    k = kilo         (navegação local, seu setor)
    S = Setor/Sistema (viagem entre regiões do universo)
    A = Anos-luz     (saltos galácticos)

IDEIA FORTE — Debounce no painel de coordenadas:
  Os números não devem ficar mudando freneticamente enquanto a
  câmera move. Atualizar o painel a cada 100ms com arredondamento
  de 1 casa decimal. Leitura estável, não "tremelica".

  Usuário digita: A 1000:1000:1000
  Sistema entende: saltar para escala de anos-luz
  Torna a navegação entre escalas muito mais ágil

PROBLEMA RESOLVIDO:
  Nicknames não podem ser a semente das coordenadas.
  Se o nick é público + algoritmo é público = qualquer um
  calcula onde você mora no COSM. Quebra a privacidade.

  IP também não: IPs se repetem (DHCP, VPN, IPs compartilhados).
  Dois usuários diferentes podem cair na mesma coordenada em
  dias diferentes. Quem construiu ali encontra "invasor".

SOLUÇÃO — FRASE SECRETA (sem Google, sem custo, sem app):
  O usuário cria uma frase secreta qualquer.
  Ex: "meu gato preto bebe cafe de manha"

  O browser usa Web Crypto API (embutida, gratuita, nativa) para:
    SHA-256("meu gato preto bebe cafe de manha")
    → hash de 64 caracteres hex
    → divide em 3 partes → X : Y : Z
    → coordenada permanente e única no universo COSM

  RESULTADO:
    Mesma frase → sempre mesma coordenada, em qualquer device
    Frase diferente → coordenada completamente diferente
    Ninguém sabe sua frase → ninguém sabe sua coordenada
    Não precisa de Google, de app, de servidor, de conta

  POR QUE É SEGURO:
    SHA-256 tem 2^256 combinações possíveis
    Hackear por força bruta levaria bilhões de anos
    O universo COSM tem coordenadas igualmente imensas
    Sem login, sem senha, sem e-mail = nada para hackear
    Hacker não sabe nem por onde começar a procurar

DOIS TIPOS DE USUÁRIO:

  VISITANTE (anônimo, sem frase):
    → IP + seed local aleatório → posição temporária de visita
    → Pode navegar, explorar, ver conteúdo público
    → NÃO pode registrar coordenadas (sem identidade permanente)
    → Se limpar o browser: nova posição gerada

  DONO (com frase secreta):
    → Frase → hash → coordenada PERMANENTE e única
    → Pode registrar, construir, guardar arquivos
    → Mesma frase = mesmo lugar em qualquer device, sempre
    → Se perder a frase: perde o espaço (como perder chave de cofre)
    → Recomendado: anotar a frase em papel físico guardado

NICK / NOME DE EXIBIÇÃO:
  Existe como apelido visual, NÃO conectado à coordenada.
  O nick é público. A frase é secreta. São coisas separadas.
  Ninguém consegue calcular sua coordenada a partir do nick.

NÃO PRECISA DE:
  → Google Authenticator (free mas exige app e setup)
  → Token de 6 dígitos (TOTP — adiciona fricção desnecessária)
  → Carteira crypto (Metamask — exige extensão, conhecimento)
  → Qualquer serviço externo pago ou gratuito

IMPLEMENTAÇÃO TÉCNICA:
  Web Crypto API → SubtleCrypto.digest('SHA-256', frase)
  → ArrayBuffer → hex string → split → parseInt → X, Y, Z
  Tudo no browser, zero servidor, zero custo
